## Should fix (cheap; affects how exact the gates are)

- **Booleans in the sharing cases aren't type-checked.** `data['enqueue_observations'] != expected_sharing` uses Python equality, so `1` or `1.0` passes for `true` (`:46-47`). The row fields and counters are type-guarded; these aren't.
