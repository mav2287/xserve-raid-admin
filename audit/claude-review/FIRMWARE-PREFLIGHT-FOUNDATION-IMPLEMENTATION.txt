## Confirmed correct

- **Exact type and bounds:** `type(snapshot) is bytes` runs before anything else. The size cap is checked before hashing, and exact size plus SHA-256 are checked before any interpretation (`tools/firmware_preflight.py:85-90`). Unknown input never reaches `zipfile`, `zlib` or a socket, because the module doesn't import any of them.
- **Read path:**
  - `lstat` rejects symlinks, FIFOs, directories and device nodes before `open`. `O_NOFOLLOW` and `fstat` then check the file type and that it's the same file (dev/inode).
  - The size is checked on `lstat` and again on `fstat`.
  - The read loop asks for at most `PACKAGE_SIZE+1` bytes in total and handles short reads.
  - Growth beyond the cap gives `SIZE_REJECTED`; shrinking, or growth below the cap, gives `READ_FAILED` because `len != st_size`. The result is converted to `bytes`.
  - `PreflightError` is re-raised before the broad `ValueError` catch, so codes aren't rewritten. `from None` drops the chained traceback.
- **Redaction:** rejections print only `{result, code}`. The argparse override covers unknown options. Success output is built only from constants, with no path and no digest of the input.
- **Fresh output:** each call builds new dicts, so a caller can't change the module's tables.
- **Provenance scope:** consistent with your note. `validate_snapshot` doesn't depend on where the file is. The checker's marker check (`check_firmware_preflight.py:52`) binds the opt-in run to cache2 (`27b667…`), and a cache1 path would fail there, as intended.
- **Frozen table vs package:** member order, sizes, method 8, digests and manifest blocks are checked against the snapshot that passed the hash gate. They're also checked against `official_fixture` rows. Parsing happens only after the hash gate and outside the guarded block, which is correct for a fixture.

## Medium: fix before regenerating evidence

**1. Some frozen provenance fields are never checked.**
- `CONTAINER_SHA256` is imported but never used (`check_firmware_preflight.py:16`).
- `CONTAINER_MEMBER` and the literal `container_size: 8052021` (`firmware_preflight.py:95`) aren't checked against anything.
- `official_fixture` checks the container against its own copies of the values (`check_firmware_archives.py:18-19,29`), not the module's constants.
- So the checker can print `acquisition` values that differ from the acquired package without failing.
- Without `--official-firmware`, none of the module constants are checked at all.

Narrow fix:
- **Always (no cache needed):** load `audit/official-firmware-fixtures.json` and assert that `official_package.sha256 == PACKAGE_SHA256`, `container_sha256 == CONTAINER_SHA256`, `acquisition_marker_sha256 == ACQUISITION_MARKER_SHA256`, and that `entries` equals the dict form of `MEMBERS`. Also assert `PACKAGE_SHA256 == OFFICIAL_SHA256` and `CONTAINER_SHA256 == OFFICIAL_ARCHIVE_SHA256`.
- **Opt-in:** read the marker bytes once, then hash and parse those same bytes. That also removes the gap between parsing at `check_firmware_archives.py:31` and hashing at `:52`. Then assert `archive_sha256 == CONTAINER_SHA256` and `selected[CONTAINER_MEMBER]['sha256'] == PACKAGE_SHA256`.
- Add a `CONTAINER_SIZE` constant, and assert that `accepted['acquisition']['container_size']` equals the container's size from `stat`.
- Compare the whole `accepted` dict to an expected value built from verified sources, not just `result` and `sha256`.

**2. The AST allowlist test can be bypassed** (`tests/test_firmware_preflight.py:77-87`).
- It only checks calls of the form `os.X(...)`.
- `from os import system` would still pass, because `'os'` is already in the import set.
- So would aliasing (`f = os.system; f()`), `getattr(os, 'system')`, and the builtin `open`.

Narrow fix:
- Check every `ast.Attribute` whose base is `os` against an allowlist: `{lstat, open, fstat, read, close, O_RDONLY, O_NOFOLLOW, O_NONBLOCK, O_CLOEXEC}`.
- Require that the only `ImportFrom` is `dataclasses.dataclass`.
- Reject the names `getattr`, `open`, `compile`, `globals`, `vars` and `breakpoint`, in addition to `eval`, `exec` and `__import__`.
